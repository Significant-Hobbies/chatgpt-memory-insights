## Why

Memory Map already has a substantial browser-only analysis product, but a new
visitor must enter the import workflow before they can understand its full
value. A public explanation route should make the outcome, capability breadth,
privacy boundary, and required ChatGPT export path legible before someone
chooses a ZIP.

## What Changes

- Add a public `/about` route in the established Memory Transit Atlas visual
  language.
- Demonstrate the product mechanism with an explicitly illustrative topic and
  memory map above the fold.
- Publish an exhaustive, source-of-truth inventory of shipped analysis,
  semantic memory, search, evidence, control, persistence, and accessibility
  capabilities.
- Explain how browser-only processing, embedding-model downloads, bounded
  semantic sampling, and optional device-local persistence work.
- Explain how to request and download a ChatGPT export, with official OpenAI
  resources and timing caveats.
- State who the product is and is not for, including current unsupported
  capabilities.
- Add a discoverable route between the app and the new explanation page.

## Capabilities

### New Capabilities

- `product-explanation`: Public product positioning, capability documentation,
  privacy explanation, export onboarding, and app conversion route.

### Modified Capabilities

None.

## Impact

- Adds one static Astro route and page-specific styles.
- Adds a small navigation link to the existing app shell.
- Updates durable product status and public documentation.
- Adds no production dependency, application API, analytics, account system,
  or runtime data flow.
